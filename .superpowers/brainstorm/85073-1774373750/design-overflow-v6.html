Edge Cases

No min/max set All overflow modes behave like unbounded
min == max (single day) Truncate modes: 1 week shown. Pad modes: weekCount weeks, most disabled.
weekCount exceeds available weeks Truncate modes: show only valid weeks. Pad modes: fill remaining rows as disabled.
All days disabled by isDateDisabled isDateDisabled does NOT affect overflow logic — only min/max do. Days rendered but disabled.
Focus target is disabled Receives roving tabindex but can't be selected. Matches month view.
Button disabled state contain/contain-truncate: disabled when next shift has 0 enabled days.
clamp/clamp-truncate: disabled when already at clamp position (shift would no-op).
unbounded: never disabled.

Month View Overflow

MonthView.Root accepts "unbounded" | "contain" only. contain disables prev/next month buttons when target month has zero enabled days. TypeScript enforces the narrowed type.
